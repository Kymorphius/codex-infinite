同步范围与设备独立设置

同步普通 Git 项目中已提交的代码和历史。两端须为同一分支且没有未提交改动，目标版本须能快进到源版本。请确认选择的是同一个项目。

各机的 Git 配置、登录凭据、依赖和被 Git 忽略的文件保持独立。Git 已跟踪文件及历史会随仓库传递，敏感内容请先检查。

正在运行的任务与会话仍在原设备。本次不迁移进程，不自动分配设备；多根项目、worktree、LFS 和子模块暂不支持。

先预检，再确认。以目标设备读回的版本和工作目录状态确认完成。
