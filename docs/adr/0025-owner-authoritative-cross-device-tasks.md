# 0025 — 跨设备任务保留来源权威

状态：接受。日期：2026-09-26。

## 决策

跨设备任务中心是各节点清单的投影，不引入另一份可写的合并数据库。任务身份为 `(ownerDeviceId, scopeId, id)`，分派目标单独记录 `(assignedDeviceId, assignedThreadId)`。编辑、分派、退回、完成、删除均回到来源节点，经完整版本 CAS 与持久 requestId 回执确认。

原生会话待办也读取该投影；不能将远端任务复制为新的本机待办。原生发送前获取来源节点持久预占，提交成功后标为已交付而非已完成。未知发送结果保留预占；仅确定没有调用发送时可携预占凭证取消，禁止以超时自动释放。

图片传输是附件适配层：根据确切任务和版本导出数据，校验引用集合、大小、类型和摘要，目标缓存使用来源设备参与的稳定标识。清单仍保留来源图片引用。不得同步整个设备 profile、凭证或运行目录。

## 理由与代价

来源权威复用已有本机清单存储，避免两个设备离线编辑后静默覆盖、同一任务被复制执行，以及本机附件路径泄露。代价是来源离线时只读缓存，不能承诺离线分派；网络响应未知时需核对而非盲重试。全局待办与原生 UI 使用同一原任务，只保留不同视图。

已发送状态不能证明任务结果完成；完成仍为用户独立动作。远端排期首版只读，实际发送仍由来源节点现有排期系统负责。Anytype 对象保持其既有权威边界，此决策不迁移 Anytype 数据。
