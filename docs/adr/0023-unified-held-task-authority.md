# ADR 0023：会话待办统一到综合任务清单

状态：接受

## 背景

直存待办原本以 `native-held-queue.v1` 的会话本地记录存在，而领取任务以综合清单任务存在，导致两套身份、退回行为和计数同步。用户明确要求两者本来都是任务，应统一模型。

## 决定

`ccc:general-inbox:v1` 是直存与领取任务的唯一任务权威源。会话待办是 `assignedThreadId` 的投影，退回是取消指派，不复制或新建任务。任务可选的有界消息载荷只保存文字和本机图片引用，图片字节留在现有 IndexedDB；综合清单“添加任务”的粘贴图片和会话“存待办”的图片采用同一载荷契约。原生排队暂停项仍属于原生队列暂存，不自动当作清单任务。

旧直存记录以原 ID 幂等迁移；在持久化回执前保留原记录，迁移成功后清除旧投影。无法安全转换的旧记录保留并报告，不自动删除。迁移与发送都采用先确认目标、后删除来源的顺序。

## 后果

所有新直存待办可退回并再次领取，原任务 ID 与附件引用不变。清单契约和持久化大小约束需覆盖结构化消息载荷；图片引用的最终垃圾回收需在确认任务不再可重试后另行实施，不能在恢复发送时提前删除。
