# 显式启用 Claude 原生内置工具

2026-09-28。用户要求在现有 Claude 面板提供完整工具开关。

采用独立模型身份 `claude-subscription/opus-native`，复用现有会话设置写入、
回读和恢复流程。原生工具默认关闭；Claude CLI 权限与 Codex 的访问授权独立。
原生工具在官方 CLI 内执行。2026-09-29 用户明确纠正：自动推理强度与
`bypassPermissions` 无冲突，所有 Claude Router CLI 启动均使用 bypass，
包括客户端工具模式和原生工具模式。这覆盖本 ADR 原先的 auto 权限决策。
它只改变 Claude CLI 自身的工具批准；桌面工具保留 Codex 客户端执行和授权，
用户 hooks、外部 MCP 与项目设置仍不自动加载。

原生工具目前以名称和完成状态显示为文字进度，不伪装成客户端执行的工具记录。
根据用户反馈，文字进度增加有界的命令、文件或搜索目标摘要；原始结果仍不直接转发，
以免将可能包含凭证的输出混入会话。该展示不改变工具执行与授权边界。
不启用额外用户 MCP/hooks/设置，不改认证来源。交互终端的全部定制仍不属于本开关。
选用独立模型身份使模式进入路由的持久绑定和续接校验，防止半轮切换执行体系。
