# 任务清单搜索

## 行为

- 项目清单、综合任务清单及领取面板的顶部增加“搜索任务”内容框，支持中文子串和不区分大小写的文字匹配，忽略搜索词首尾空格。
- 综合清单同时搜索未指派任务和会话待办；领取面板只筛选原本可领取的任务，不改变状态范围。
- 输入即时筛选、显示匹配数量，并提供“清空”恢复全部结果。没有结果时显示“没有匹配的任务”。搜索框 Enter 不新增、领取或发送任务。
- 搜索只控制现有行的可见性，不重建列表、不修改任务数据、加入时间、排序或领取数量；隐藏后清空搜索仍能恢复未保存输入及相同任务行。
- 后台正常数据更新重建列表时沿用搜索词；重新打开或切换清单时清空搜索，避免残留条件造成任务看似消失。
- 没有轮询、MutationObserver、网络搜索或定时器。每次输入只扫描当前列表的任务内容，并且仅写入发生变化的 DOM 属性。

## 共用面板

- 指派与领取入口使用同一面板、搜索栏、多行内容编辑器、时间显示和草稿保护；仅由当前入口决定任务操作按钮。项目清单也复用内容编辑器。
- 指派模式保留“指派会话／删除”和完成状态；领取模式对可领取任务显示“领取”。综合清单保留原有下方会话待办分区，领取模式不加载不相关的已指派／已完成任务。
- 指派确认和领取都读取内容框最新值，即使尚未失焦也不会提交旧文本；选择会话期间再修改文本，确认时仍以最新值为准。
- 共用编辑器负责自动保存、长度校验、旧状态保护以及后台刷新后保留未提交草稿和选区，不维护两种编辑实现。删除旧的领取专用编辑模块。
