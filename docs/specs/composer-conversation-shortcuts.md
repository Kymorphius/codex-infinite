# 输入框上方的会话快捷入口

将“消息搜索 / 最近会话 / 最近发送”从顶部标签栏移到当前可见输入框上方左侧，保留三者原有的点击、搜索和导航行为。顶部标签栏只保留页面标签。

快捷入口使用独立于原生 React 输入框的浮动容器，按输入框边界定位，不向原生节点插入子元素。没有可见输入框时隐藏。最近会话与最近发送菜单向上展开，避免底部截断；窗口尺寸或会话切换后重新定位。搜索的侧栏入口继续保留。

验收：三入口与输入框左边对齐、位于输入框上方；顶部不再重复显示；菜单和搜索仍能使用；输入框重建后快捷入口能恢复，且不引起持续 DOM 重排。

最近列表采用底部起点：最新记录靠近底部入口，旧记录向上排列。每次打开滚到底部并聚焦最新项；接近顶部时分批插入旧记录，补偿新增高度以保持当前阅读位置。后台刷新同序记录不重建列表，不改变滚动位置。

快捷工具条必须占据输入框上方的真实布局空间，不能覆盖 Goal、任务或待办。保留输入框原有上边距，额外预留工具条高度和间隔；窗口/输入框/工具条尺寸变化时重新定位。切换输入框或卸载时撤销旧节点上的预留空间。用定向 ResizeObserver，不增加轮询或全页观察器。
