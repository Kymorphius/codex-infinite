# 输入框上方的会话快捷入口

将“消息搜索 / 最近会话 / 最近发送”从顶部标签栏移到当前可见输入框上方左侧，保留三者原有的点击、搜索和导航行为。

2026-09-28：退役顶部“控制台／会话标签”栏，不再创建可见标签节点，不再接管原生标题和预留顶部 36px。升级时销毁旧控制器，恢复原生标题和布局。保留内部历史与导航接口，供最近会话、最近发送、终端及侧栏导航使用；不删除会话、不清空记录。输入框快捷工具条继续正常工作。

快捷入口使用独立于原生 React 输入框的浮动容器，按输入框边界定位，不向原生节点插入子元素。没有可见输入框时隐藏。最近会话与最近发送菜单向上展开，避免底部截断；窗口尺寸或会话切换后重新定位。搜索的侧栏入口继续保留。

验收：三入口与输入框左边对齐、位于输入框上方；顶部不再重复显示；菜单和搜索仍能使用；输入框重建后快捷入口能恢复，且不引起持续 DOM 重排。

最近列表采用底部起点：最新记录靠近底部入口，旧记录向上排列。每次打开滚到底部并聚焦最新项；接近顶部时分批插入旧记录，补偿新增高度以保持当前阅读位置。后台刷新同序记录不重建列表，不改变滚动位置。

快捷工具条必须占据输入框上方的真实布局空间，不能覆盖 Goal、任务或待办。保留输入框原有上边距，额外预留工具条高度和间隔；窗口/输入框/工具条尺寸变化时重新定位。切换输入框或卸载时撤销旧节点上的预留空间。用定向 ResizeObserver，不增加轮询或全页观察器。

打开可见 dialog/alertdialog（含钩子授权弹窗）时隐藏整个快捷工具条及其子菜单；关闭后恢复。隐藏期间保留已预留的空间，避免背景布局跳动。忽略关闭、隐藏或没有布局矩形的弹窗；复用已有 DOM 观察器处理弹窗显隐属性。

视觉融合：作为输入区的辅助工具栏，与原生 Goal 栏一样左右内缩 12px，宽度跟随输入框。复用输入框实际底色和字体，半径 16px，弱边框，无独立阴影及背景模糊；13px 常规字重、30px 最小按钮高度和统一单色 SVG。保留键盘焦点、悬停与按下反馈，减弱工具栏而不改动原生 Goal 卡片及其动作。

窄于 430px 的工具条采用等宽、居中的三个图标入口，保留悬浮提示及无障碍名称。图标模式只由工具条可用宽度决定；菜单与整个工具条左侧对齐并限制为工具条宽度。两个菜单指示箭头朝上，与实际展开方向一致。

原生排队消息等普通菜单与工具条重叠时，临时隐藏工具条，避免遮住菜单选项；不重叠的菜单不影响工具条。工具条自己的上拉菜单不触发此规则。菜单关闭后恢复，不重新计算 Goal/输入框的布局占位。

模型选择与推理强度面板打开时主动让出工具条区域，包括未使用 menu/dialog 角色的原生浮层。依据原生模型/推理入口的展开状态和可见面板控件判断，关闭后恢复；沿用已有观察器，不添加轮询或修改模型设置。
