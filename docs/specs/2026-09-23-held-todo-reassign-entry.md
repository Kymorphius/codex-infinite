# 会话待办增加重派入口

会话“待办”面板中，来源为综合任务清单且已领取到当前会话的行，在“恢复”“退回”旁增加“重派”。点击后打开原生综合任务清单，定位同一任务并展开原有“改派会话”选择器；用户确认前不修改归属、不发送消息，也不生成第二条任务。

- 只允许当前会话、任务 ID、原文和已指派状态都仍匹配的项进入重派；导航后的旧行必须失效。
- 目标会话继续由原生清单的会话候选和保存流程决定，保留原任务 ID、加入时间和图片输入。
- 清单未就绪或任务状态变化时显示明确错误，不能静默退回或自动派发。
- 重派成功后原同步流程更新两边的待办投影。

验证：精确身份和当前会话保护、选择器打开但未写入、`npm run check`、`npm test`。实际原生界面点击单独验收。
