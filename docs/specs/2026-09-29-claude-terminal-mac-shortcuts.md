# Claude 终端的 Mac 快捷键

用户在托管 Claude CLI 会话中需要用 ⌘V 粘贴截图，并用 ⌘↵ 将排队消息立即送出。
Claude CLI 自身识别 Ctrl+V 图片粘贴，以及 Ctrl+X Ctrl+S 的 `chat:sendNow`；
后者在不报告扩展按键的终端中仍可靠。

- 仅 `kind: claude` 的托管终端启用映射；Shell 会话和普通原生 GPT 输入不变。
- 终端画布和底部输入框收到图片剪贴板的 paste 事件时阻止普通粘贴，向当前
  已连接的 Claude PTY 发送一次 Ctrl+V；文本剪贴板沿用既有粘贴行为。
  不读取或持久化图片内容，也不改变系统剪贴板。
- ⌘↵ 在终端画布发送 Ctrl+X Ctrl+S。底部输入框若有草稿，先通过现有安全
  粘贴路径将草稿交给同一 PTY（不按 Enter），成功后再发送该序列；失败不插队。
- 连接未就绪、只读、正在发送或会话已退出时，不补发快捷键；不自动重试。
  显示层的快捷键不会绕过 Claude 自己的排队和权限流程。

验证图片与文本粘贴区分、⌘↵ 顺序、草稿失败、Shell 隔离、未连接隔离及卸载清理；
运行 `npm run check` 和 `npm test`。真实系统剪贴板与原生界面仍需加载后验收。
