# 看板后台学习管理

## 行为与范围

在 Hermes 桌面看板标题栏增加后台学习入口，展开后查看当前看板最近 10 次
复盘、实际技能动作、错误或跳过原因，并启停当前看板的后台学习。
既有看板白名单保持原样，不自动扩大范围，不补跑历史，不提供自动重试。
关闭阻止尚未开始的复盘，已经运行的复盘会继续完成。

## 数据与所属

沿用 Hermes Kanban 插件 REST 通道及其认证，不新增端口或模型工具。
后端校验看板身份，先按看板筛选再取最近记录；前端按看板缓存，切换时不能
显示或修改上一看板的数据。显示失败、未知和无变化完成，不能把完成计作学习成果。
作业正文和任务结果不进入列表。配置变更仅修改 background_learning，并保留
其他看板；使用原生配置锁和保存机制。全局暂停且已有白名单时，单看板启用
不得顺带恢复其他看板。过期的配置修订返回冲突并要求刷新。

## 验证

隔离 profile 验证启停、白名单保留、过期修订、缺失看板、按板过滤和只读无写入。
前端验证加载失败、无变化完成、实际动作及开关失败。真实面板读取既有验收记录，
仅在验证看板上测试开关并恢复原设置，确认其他看板保持不变。执行类型检查、
相关测试、构建及 Control Console 必需检查，交付前保存本地 Git。
