# 共享项目侧栏创建会话

共享项目总览、仓库与工作目录的加号必须直接创建 GPT 原生会话并打开它。显式携带 codex 项目身份，不根据 cwd 猜测所有者；不进入 Hermes 会话创建或切换 Git 分支流程。已有草稿保持原会话所有权。

Personal Panel 在 POST /api/shared-sessions 接受 project_id、cwd 可选、title 可选并交给原生 operations.create。未知字段拒绝。目录必须来自该项目登记目录或该项目已有共享会话的 cwd；目录需真实存在。未经索引认可的目录拒绝，不创建或切换工作树。缺省目录保留看板现有行为。

前端创建期间防重入。成功后通知侧栏刷新并导航到返回的共享 ID。创建成功但重命名失败保留已有 warning，不重试创建。错误应可见；不回退创建 Hermes 会话。普通项目加号不变。

验证：原生目录归属边界测试、Panel API 路由与字段验证、侧栏组件防重入及失败测试、TypeScript 构建；完整 Console 和 Panel 检查测试；安装后实际点击共享项目加号，验证项目、目录、空历史和首条发送。

实际界面验收发现共享侧栏 message_count=1 为存在性占位；空历史误触普通会话丢失保护。共享会话仅在本次原生恢复明确返回 message_count=0 时接受空历史。未知计数、读取失败及普通会话仍保留保护。
