# 自定义侧栏入口图标

将四个自定义入口共用的 ⌘ 替换为可区分的单色线条 SVG：控制台使用终端窗口、看板使用三列面板、会话中心使用双对话气泡、项目优先级使用排序箭头和递减横线。

图标统一使用 24×24 viewBox、1.75 描边和 currentColor，显示尺寸保持 1.1rem，不收缩、不接受焦点，对辅助技术隐藏。入口名称、顺序、点击行为不变；原生侧栏入口和备用入口使用同一组静态图标，只修改本产品创建的按钮。

图标定义放在独立静态资源模块，注入器按模块标识选择。更新注入版本使已有入口在下次安装时更新。

验证：四种图标内容不同，尺寸、主题色和无障碍属性一致；两种入口均按模块选择图标；生成的注入脚本可解析；运行 npm run check 和 npm test。
