# 原生页签标题控件扫描减负

## 问题与目标

页签定位会周期性遍历整页按钮并读取几何信息。Windows 的侧栏、最近会话菜单和轮次轨道会把按钮数量推到上千，即使页面上没有需要接管的顶部聊天操作，也会执行完整扫描。目标是只在确有可见顶部操作时进行完整扫描，不删减任何增强入口。

## 行为约束

- 仅在宽工作区使用语义预检；窄工作区保留既有完整扫描与定位回退。
- 侧栏内或完全位于可见区域上方的“聊天操作”不是标题控件；真正与顶部可见区域相交的操作仍触发原扫描。
- 跳过扫描时保留已连接的缓存节点和既有标题接管状态；不改变页签、最近会话菜单、草稿、批注或导航逻辑。
- Windows 运行版此前一次双模块部署后曾失去响应；本次只允许单模块分阶段验证，运行态不可用时恢复原文件与增强功能。

## 验证

- 单元测试覆盖顶部操作、侧栏操作、屏幕外操作、窄工作区回退及扫描跳过。
- 运行完整检查与测试；如 Windows 空闲且获准重启，单独部署标题扫描模块并读回窗口、注入版本和会话内容，再测性能。
