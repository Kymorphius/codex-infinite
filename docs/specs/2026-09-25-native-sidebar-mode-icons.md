# 原生侧栏模式按钮比例调整

## 背景

原生 ChatGPT 侧栏标题右侧的 Turbo 与全局路由使用文字胶囊按钮，挤占标题空间。用户希望整体界面只做小幅比例调整，并指定这两个按钮改为 SVG 图标。

## 范围

- 将侧栏头部的 Turbo 与全局 Jev 路由按钮分别改为紧凑、等尺寸的内联 SVG 图标按钮，减少占用宽度。
- 保留开关状态的颜色、`aria-pressed`、可访问名称、悬停说明，以及左键切换和右键设置行为。
- 保留输入框内的当前会话路由文字按钮；不改变侧栏整体结构、原生宽度或路由策略。
- 更新注入版本，使已打开页面能够在下一次正常注入时替换旧按钮。

## 验收

- 两个侧栏按钮均只显示图标，图标不参与无障碍朗读，按钮仍能说明状态。
- 激活、关闭、同步中的视觉状态与交互语义保持可辨认。
- 现有相关测试、`npm run check`、`npm test` 通过；核对生成的注入脚本。
