# 任务清单与领取视图的输入区

## 目标

共用任务面板需要让“记录新任务”和“查找已有任务”一眼可辨，同时领取视图不能暗示可以在这里新增任务。

## 行为

- 综合任务清单和项目清单按标题、简短说明、添加框、搜索框、数量、任务卡片排列。添加框前显示单色线框加号，搜索框前显示单色线框放大镜；图标只作视觉提示，输入框保留原有无障碍名称，不使用 emoji。
- 已有会话和新建任务页的领取视图隐藏添加框，只显示带图标的搜索框及领取说明。切换回普通清单时恢复添加框。
- 输入区与任务项以间距和弱对比底色分层，不叠加多重装饰边框；只在输入区或任务编辑框聚焦时显示边界。不把说明夹在两个输入框之间。共用的搜索、直接编辑、领取、任务排序及保存逻辑不变。图标不增加观察器或定时器。
- 任务内容输入框默认一行高度；多行内容按内容适度增长并限制最大高度，过长时可在框内滚动。收紧卡片内边距与行间距，加入时间仍保留。
- 面板在桌面宽度下可扩展到约 760px；加入时间与任务内容、操作同排，空间不足时才自然换行，不截断时间或任务文字。

## 验证

- 覆盖普通清单、两种领取视图以及切换后的输入区可见性与顺序；回归搜索和添加行为。
- 运行仓库检查及测试，并重载本机服务。原生界面若无法访问，单独标注未完成可视验收。
