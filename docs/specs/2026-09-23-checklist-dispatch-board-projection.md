# 综合任务清单接入控制台主页任务看板

## 范围

控制台主页“任务看板”展示综合任务清单中的同一任务，按未指派、会话待办、已完成分区；原有排期和发送流程保留为独立分区。任务清单存储仍是这些任务的唯一权威，页面只读取投影，不创建调度副本、不自动发送、不改变领取或完成状态。

## 契约

- `/api/dispatches` 附带有界的 `checklistItems` 投影，字段仅含任务 ID、文字、加入时间、完成状态和已指派会话 ID，不包含图片字节和请求回执。
- 读取失败不伪装成空清单，返回清单错误状态；已有调度任务仍可读取。
- 看板每次沿用现有刷新周期读取权威清单；编辑、领取、退回、完成后按原任务 ID 进入相应分区，不复制记录。
- 本轮只接入综合任务清单；项目专属清单的键尚未有服务端可枚举索引，不能靠猜测文件名读取。看板暂不提供任务清单的修改入口。

## 验证

- 投影身份、状态和字段边界测试；HTTP 读取与失败契约；页面分区与筛选测试。
- 运行 `npm run check` 与 `npm test`；实际桌面界面单独验收。
