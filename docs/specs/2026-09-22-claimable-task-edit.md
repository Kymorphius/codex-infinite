# 领取列表编辑任务

## 行为

- 根据用户后续确认，领取列表内容框直接可编辑，旁边仅保留“领取”，不增加编辑／保存／取消步骤。
- 离开内容框时自动保存修改；Enter 仅保存，Shift+Enter 换行，输入法确认不会误提交，保留多行原文。
- 点击领取原子提交当前框内的最新内容及会话归属，即使没有触发失焦保存，也绝不使用旧文本。领取后仍是暂停待办，不自动发送。
- 自动保存更新同一任务，不新增、不领取、不发送；保留任务 ID、加入时间和排序。保存草稿沿用清单现有持久化及确认机制。
- 空白或超长内容不给予保存或领取并显示提示，保留输入以供修正。
- 保存及领取前检查原行仍属于当前面板/领取会话、原任务仍未完成且未指派，且原文未被其他更新替换。旧行事件不能覆盖新状态。
- 不增加轮询或 DOM 观察器。领取列表仅展示可领取任务，不加载无关的会话待办，以免异步加载打断编辑。
- 自动保存不重建当前行，避免失焦保存吞掉紧接着的领取点击。其他任务后台变化引起列表重建时保留当前草稿、焦点和光标；原任务被外部修改时保留草稿但拒绝覆盖新原文。

## 验收

- 回归直接编辑、未失焦领取最新文本、自动保存后继续输入再领取、空白及超长校验、待保存重载、时间不变、旧回调及并发任务更新保护。
- `npm run check`、`npm test`，并在实际领取面板用临时任务验证编辑保存；不发送用户任务。
