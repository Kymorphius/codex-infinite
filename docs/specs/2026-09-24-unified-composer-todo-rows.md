# 会话待办面板统一行布局

会话待办面板同时投影本地暂停/历史待办与综合任务清单中指派给当前会话的任务。它们保留各自的存储权威，但在面板里必须由同一个行渲染器呈现：统一“待办”标签、内容区域、操作区域和基本动作顺序，不再把领取任务追加成另一种行样式。

- 排队消息继续显示“排队”；待办项不再用“直存/暂停”等来源前缀造成两套视觉。原始加入时间仍可悬浮查看。
- 基础动作按“编辑/排序（若支持）→恢复→来源专属动作”排列。清单任务保留“重派/退回”，本地历史待办保留“删除”；不可用动作不显示空壳按钮。
- 不迁移、删除或复制任何待办。不同来源的恢复/退回行为继续调用原有已验证路径；旧行与会话切换校验保持有效。
- 手动视图保持现有各来源内部顺序；时间视图按已知最初加入时间对所有待办统一排序，未知时间稳定排在末尾。

验收：两类待办共用一个行创建入口，视觉标签一致，动作顺序稳定；`npm run check` 与 `npm test` 通过。原生界面仍需实机点击验收。
