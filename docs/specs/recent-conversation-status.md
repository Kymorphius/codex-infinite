# 最近列表的统一状态与可靠收录

最近会话与最近发送共用原生任务状态及当前窗口的未读投影，不把导航历史当作状态来源。复用 AttentionConversationService 的状态/未读读取，不增加轮询。两菜单同时刷新状态，未变化行不重建。

已完成且未读使用未读圆点和“已完成，未读”标签；已读完成才使用勾。未读信息不可用时不推断已读。原生侧栏查找支持 local: 前缀。

最近发送仍只收录已验证用户消息，不用更新时间伪造发送时间。文件部分未完成或有无法解析的记录时，有已验证发送时间的会话仍收录并标记快照 stale，保留已知的较新时间。无有效时间的记录不纳入。

Windows 的历史漏项报告尚未现场复现；此修复覆盖已识别的跨平台过滤缺陷，不声称已验证那次故障。
