# Claude 原生工具开关

状态：代码已实现，自动检查通过；运行界面加载与真实订阅验证待完成。

Claude 面板新增当前会话的「Claude 原生工具」开关。新会话默认开启；已有会话
保存过的开关选择优先，显式关闭仍保持关闭。关闭使用现有
Codex 工具模式；开启选择 `claude-subscription/opus-native`，由官方 Claude CLI
加载完整内置工具集合与技能命令，并保留客户端 MCP / Computer Use。
保存后回读模型及强度；刷新保留开关；恢复原生模型还原最初的 GPT 设置。
运行中禁止切换。其他会话和全局访问权限不变。

原生工具由 Claude CLI 执行。用户要求此项目的 Claude 路由与托管终端一样使用
`bypassPermissions`，不因推理强度选“自动”而改用 `auto` 权限模式。CLI 对可用的
内置工具不弹权限确认；客户端 MCP / Computer Use 仍由 Codex 自己授权执行，
CLI 的 bypass 不会修改客户端权限。用户 hooks、外部 MCP 与项目设置仍不
自动加载，避免悄悄启动额外服务或改变订阅认证；这是完整内置工具模式，不等同
于复制用户交互终端的所有配置。不注入 Codex 技能目录。

Router 将模式纳入伴生身份和进行中的工具续接校验；不同模式不能复用活动轮次。
原生工具名称与成功/失败通过文字进度展示，Codex 工具仍使用原生调用记录。

工具进度应让用户看出正在做什么：Bash 显示描述和命令，读写编辑显示目标文件，
搜索显示模式及路径；完成时显示成功/失败，若 CLI 提供退出码则一并显示。
摘要长度有上限，原始工具结果（可能包含文件内容或凭证）不直接并入会话文字。
这些仍是 Claude CLI 自己执行的工具，不伪装成 Codex 客户端工具调用。

在原生 Codex 会话时间线里，严格匹配上述 Router 工具进度文字并以接近原生 GPT
工具活动的紧凑行呈现：命令、读写文件等有图标、状态与可展开的有界摘要。
同一轮中同一操作的执行中/完成事件合并为一行；不匹配的普通回复保持原样。
这只是本机展示层，不创建 Responses 工具调用、不向客户端发起第二次执行；
保留原始会话消息用于回放和降级。失去注入时仍能读到原文字。

验收：开关保存、重载、还原与失败回滚；仅显式 native 模型开启 CLI 原生工具；
所有 Claude Router CLI 启动均传 bypass，自动推理强度不传 `--effort`；模式改变拒绝续接；工具进度不执行第二遍。单元与仓库检查之后，
另行标明实际界面及订阅调用验证情况。
