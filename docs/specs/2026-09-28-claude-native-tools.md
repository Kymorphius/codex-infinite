Codex 工具模式；开启选择 `claude-subscription/opus-native`，由官方 Claude CLI
加载完整内置工具集合与技能命令，并保留客户端 MCP / Computer Use。
保存后回读模型及强度；刷新保留开关；恢复原生模型还原最初的 GPT 设置。
运行中禁止切换。其他会话和全局访问权限不变。

原生工具由 Claude CLI 执行。用户要求此项目的 Claude 路由与托管终端一样使用
`bypassPermissions`，不因推理强度选“自动”而改用 `auto` 权限模式。CLI 对可用的
内置工具不弹权限确认；客户端 MCP / Computer Use 仍由 Codex 自己授权执行，
CLI 的 bypass 不会修改客户端权限。用户 hooks、外部 MCP 与项目设置仍不
自动加载，避免悄悄启动额外服务或改变订阅认证；这是完整内置工具模式，不等同
于复制用户交互终端的所有配置。不注入 Codex 技能目录。

Router 将模式纳入伴生身份和进行中的工具续接校验；不同模式不能复用活动轮次。
原生工具名称与成功/失败通过文字进度展示，Codex 工具仍使用原生调用记录。
