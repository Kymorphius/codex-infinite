# 在目标设备创建已提交项目副本

- Status: implemented; native registration and late-confirmation recovery verified
- Date: 2026-09-29

用户选择已登记的洁净源项目、另一台设备、目标设备配置的创建父目录及新目录名，预检确认后创建。仅传输已提交 Git 历史，复用现有 bundle 内容与凭据过滤；不复制源 Git 配置、会话、依赖或 ignored 文件。

目标只接受配置的 projectCopyRoots 下一级不存在的目录。父目录必须可读写、规范且非符号链接，不处于已有 Git 仓库内；预检和执行均重新核验。目录名采用跨平台保守规则，拒绝路径分隔符、保留名称和尾随点空格。mkdir 的排他创建避免覆盖现有目录，创建后失败保留副本及私有操作记录，不删除用户可能已经使用的数据。

预检在目标私有临时目录验证 bundle，短时一次性 token；源版本执行前复核。目标执行重新核验 Git 对象与目录，创建独立 Git 仓库后经运行中的原生 projects.createProjectForRoot 完成登记，再从原生运行时项目登记清单及 Git HEAD 独立读回（空项目可能不出现在侧边栏）。原生确认对话框保持原样，不替用户绕过目录授权。未知版本能力在写目录前失败关闭。操作结果未知不自动重放写入；已有目录始终拒绝再次创建。失败提示保留目录，可通过目标原生界面登记后继续已有副本同步。

新接口继承 exact-origin 浏览器写入、节点签名与防重放、请求上限及 SSH mutation 不重试。新目录创建属于显式授权的产品能力，不改变现有同步只能访问已登记根目录的限制。新副本创建不自动修改源端共享身份；成功后用户可在已有同步页预检并关联。

验收：真实 Git 新副本、既有目录/符号链接/父目录逃逸/嵌套仓库拒绝、源变化与过期/重复 token、未就绪原生能力、取消登记及失败保留、签名路由及 mutation 无重试；真实页面流程和原生登记分别记录。保持本机活动终端，不为部署强制重载。
