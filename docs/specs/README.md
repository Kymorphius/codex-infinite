# Product specifications

Specifications are living records of product changes. Create one file per meaningful change using `YYYY-MM-DD-short-name.md` and copy `template.md`.

Statuses: `proposed`, `accepted`, `in-progress`, `shipped`, `superseded`.

A shipped spec must describe the actual implementation and link its acceptance criteria to tests or verification evidence. It is not a wish list and should not be silently rewritten to hide deviations.
