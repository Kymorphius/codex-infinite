# Hermes 共享 GPT 会话操作补齐

## 交付范围

在看板中直接新建、选中所属项目的真实 GPT 会话；共享会话发送附件、读取和修改
原生模型与推理设置、显示并处理原生审批，支持重命名、归档和恢复。
已有看板的后台学习开关继续由用户选择，不自动扩大白名单。

## 所属与接口

会话身份、历史、执行和审批仍由原生 GPT 拥有。创建和管理走原生所属进程，
不得改写索引数据库或复制历史。Hermes 只缓存归一化投影。
看板的新建按钮先创建会话并选中，再由现有执行目标合同提交卡片；不在失败重试
时偷偷创建第二条会话。创建结果不明时明确提示查看原生列表。
模型选项来自原生运行时，变更后回读；不把 Hermes 模型目录冒充 GPT 模型目录。
审批须携带会话、轮次和一次性令牌，仅提交用户明确点击的决定。
附件只传递用户选中的本机文件，通过原生输入流程提交，保留草稿冲突保护。
不自动点击业务审批、不降低权限、不发送验证以外的用户草稿。

## 验收

逐项验证真实界面和所属状态：新会话项目归属与首轮回复、附件内容可读取、模型
设置回读、审批显示与过期保护、重命名和归档恢复。测试使用独立验证会话和文件，
不得修改现有业务会话。加载失败、未支持选项和不确定写入需明确显示。
完成相关回归测试、各项目必要检查，保留其他会话的差异并按阶段本地 Git 保存。
