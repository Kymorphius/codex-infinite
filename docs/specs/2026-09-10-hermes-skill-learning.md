# Hermes 技能复用与学习接入

## 目标与范围

扩展现有本机 Hermes 上下文 MCP，让原生 GPT 查找并完整读取 Hermes 技能，
在当前用户授权的任务范围内把经过验证的流程保存成技能，或修正已有技能。
不改变原生会话执行权，不开启后台自我改写、技能同步或远程安装。

## 契约

- `hermes_skills_list` 复用 Hermes 原生文件技能索引，按关键词返回分页元数据，
  遵守平台、环境和禁用过滤。范围是当前 profile 与明确配置的外部技能目录；
  插件动态技能不在此接口覆盖范围，返回值明确标示。
- `hermes_skill_read` 通过原生 `skill_view` 的文件读取路径获得完整 SKILL.md 或
  技能内相对文件。关闭预处理，不运行内联 shell，不捕获凭证或准备执行环境。
  原文不分页、不静默截断；超过单次上限返回错误。返回来源和内容修订摘要。
- `hermes_skill_update` 调用原生 `skill_manage`，支持 create、patch、write_file。
  只写当前 profile 的本地技能，拒绝外部目录和已启用同步的技能。既有文件更新
  需要先读并提供修订值，过时读取返回错误；原生写入审批、内容验证和更新记录
  保留。`saved` 与 `staged` 分开报告。此接口不提供删除、审批绕过或执行脚本。
- 技能读取不等于执行授权。用户授权的可复用流程可以保存；一次性完成日志和
  未验证的推测不能自动固化成技能。工具指引保持简短，不重写既有系统提示词。
- 看板任务可在正文请求读取并使用某个技能；原会话通过这些 MCP 工具完成。
  保留继续原会话时不覆盖模型、技能预加载和审批配置的既有契约；本阶段提供
  按需技能读取，不改变原生会话的预加载工具集或后台 curator。

## 验收

临时 profile 测试真实原生导入与协议调用：创建、发现、完整读取、修订后更新、
引用文件写入和读取、审批待处理、禁用/外部/同步技能拒写、路径穿越与过时修订
拒绝、读取不执行命令。实际原生共享会话使用隔离测试 profile 走完保存—复用—
更新—再读取；正式环境只做发现和读取验证。更新后移除测试服务并检查正式工具。
Hermes 针对性测试与 Control Console 的检查、全量测试通过后保存本地提交。
