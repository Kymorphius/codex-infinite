# Windows 帮助菜单宿主操作

## 问题与范围
Windows 已部署菜单代码，但宿主动作绑定被独立控制台开关禁用；顶栏帮助菜单也未被识别。

## 设计
- 宿主动作绑定与独立控制台显示方式分离。Windows 保留嵌入控制台，不调用 macOS 窗口启动器。
- 顶栏帮助及左下角帮助菜单均提供“启动原版”“重启加强版”，只向当前打开的帮助菜单插入一组按钮。
- 复用现有经过请求归一化的宿主绑定；原版使用当前设备原版配置，重启仍必须明确确认。
- 不新增 HTTP 通路，不复制设备配置，不修改登录资料，不改变安全边界。

## 验收
覆盖两个帮助入口、菜单重建、取消/确认重启、Windows 原版与重启服务路由；运行 check 和全量测试。Windows 234 回读实际菜单并记录部署验证，避免为测试中断活跃任务。

## 验证记录
- 2026-09-27：语法与结构检查通过；1362 项测试通过。
