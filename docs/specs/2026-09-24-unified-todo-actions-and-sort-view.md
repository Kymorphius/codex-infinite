# 统一待办动作与独立排序视图

会话待办的权威记录是综合任务清单中指派给该会话的任务。旧本地待办（包括从发送队列暂停的消息）是迁移中的安全副本：先在任务清单保存并获确认，再按身份和内容匹配清理旧副本。迁移期间同一 ID 只展示一行，不能静默丢弃输入或图片。

管理视图中每个已入清单的待办提供编辑、恢复、重派、退回任务中心、删除。编辑保留非文字输入，删除只作用于身份与当前会话匹配的任务。重派沿用现有会话选择器；退回变成未指派任务；两者均不自动发送。旧本地项迁移尚未发起时可恢复或删除；已有待保存迁移操作时，相关动作提示等待同步，以免出现重复发送或删除后又复活。其余动作也不能假装成功。

排序视图独立于管理视图，只显示条目、加入时间和上移/下移，不显示编辑、恢复、重派、退回、删除等管理按钮。排序结果按会话存储，默认按最初加入时间从早到晚；时间视图始终按加入时间展示，不改手动顺序。发送队列如进入排序视图也只保留排序动作，不允许发送/暂停类管理操作。

验证：迁移幂等和确认后清理、身份保护、编辑保留图片、重派/退回/删除不误发、排序视图无管理按钮、`npm run check`、`npm test`。
