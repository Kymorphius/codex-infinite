# 原生会话 Claude Router 快捷切换

- 状态：已实现，原生界面仍待人工验收
- 日期：2026-09-28

## 行为

- 原生会话输入区的 Claude 控件左键在原生 GPT 设置与 Claude Router 模型之间切换。首次开启使用 Claude CLI 自动推理强度；之后按当前会话上次选择的强度和工具模式开启。再次左键恢复启用前回读的模型与强度。切换仅作用于当前已有的本机会话，生成期间不改设置。
- 右键控件在按钮附近打开设置面板。面板仅保留推理强度、Claude 原生工具和必要的操作/状态；不展示解释段落。选择自动时 Router 启动 Claude CLI 不传 `--effort`，让 Claude 使用自身默认策略。固定档位仍显式传递。
- Claude 自动与固定档位使用不同的 Router 模型标识。原生客户端的 `reasoningEffort` 仍使用模型目录支持的值；Router 从模型标识识别自动档。更改设置经原生线程设置回读确认；失败回滚。
- 面板相对按钮定位，视窗边缘自动内缩；外部点击、Escape、路由变化关闭。按钮仍保留键盘激活。
- 底部切换按钮悬停显示手形指针；选中 Claude 时使用暖橘色文字、边框与轻背景突出状态，切回 GPT 后清除该高亮。

## 验证

- 控制器测试覆盖自动/固定档切换、恢复与回读失败；渲染测试覆盖左右键与面板位置；Router 测试覆盖自动档省略 CLI 参数及模型路由。
- `npm run check`、`npm test`。原生 Codex 界面被 Computer Use 明确拒绝访问，因此运行中的按钮位置与手势需人工回读确认。
